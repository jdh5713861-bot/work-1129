## 🚀 깃허브(GitHub) 업로드 및 영상 배포 방법

### 1. MP4 영상 파일 크기 확인 (안심하고 업로드 가능)
* **파일 용량**: `16.5 MB` (17,297,614 bytes)
* **GitHub 업로드 기준**:
  * 웹 브라우저(GitHub.com) 직접 업로드 제한: **25 MB** (16.5 MB이므로 통과 ✅)
  * 일반 Git Push(터미널/GitHub Desktop) 제한: **100 MB** (16.5 MB이므로 Git LFS 설치 불필요 ✅)

---

### 2. GitHub 웹사이트에서 바로 업로드하기 (가장 쉬운 방법)

1. [GitHub.com](https://github.com)에 로그인하고 새 저장소(New Repository)를 생성합니다. (예: `ai-ethics-guide`)
2. 저장소 메인 화면에서 **`Add file` ➔ `Upload files`** 버튼을 클릭합니다.
3. `WEB` 폴더 안의 모든 파일들을 브라우저 화면 안으로 **드래그 앤 드롭**합니다:
   * `index.html`
   * `style.css`
   * `script.js`
   * `guide_motion.mp4`
   * `watercolor_bg.png`
4. 하단의 **`Commit changes`** 초록색 버튼을 누르면 업로드가 완료됩니다!

---

### 3. GitHub Pages로 무료 웹사이트 배포하기 (영상 실시간 스트리밍)

업로드 후 전 세계 누구나 웹에서 영상을 보고 체크리스트를 실행할 수 있도록 배포할 수 있습니다:

1. 저장소 상단 메뉴의 **`Settings`** 탭을 클릭합니다.
2. 좌측 사이드바에서 **`Pages`** 메뉴를 클릭합니다.
3. **Branch** 설정에서:
   * `None`을 **`main`** (또는 `master`)으로 변경
   * 폴더는 **`/ (root)`** 선택 후 **`Save`** 클릭
4. 약 1분 후 상단에 생성된 웹 주소(`https://<내아이디>.github.io/<저장소명>/`)로 접속하시면 설치 없이 바로 동작합니다!
